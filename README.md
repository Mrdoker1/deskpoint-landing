# Deskpoint Landing

Маркетинговый сайт продукта **Deskpoint**.

- Копия на русском для владельцев сервисного бизнеса в РФ
- Без чужих логотипов, выдуманных метрик, отзывов и несуществующих сертификатов
- CTA: заявка на демо (`#lead` / mailto) и вход в кабинет

```bash
cd apps/deskpoint-landing
npm install --legacy-peer-deps
npm run dev   # http://localhost:3010
```
